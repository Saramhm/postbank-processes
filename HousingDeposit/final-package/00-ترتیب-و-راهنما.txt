مسیرها (در BPMN)
-------------------------------------------------
ستاد، مدیر مستقیم = معاون / مدیر امور:
  شروع ← تأیید مدیر مستقیم ← رئیس سرمایه انسانی ← کارشناس ← مدیرکل سرمایه انسانی ← (رونوشت بازرسی، موازی) ← رئیس سرمایه انسانی (ارجاع) ← ارجاع شعبه ← حقوقی ← پرونده ← رئیس شعبه ← رئیس حوزه حسابداری (تأیید) ← واریز ← رئیس شعبه ← ذی‌حساب ← بانک اطلاعات
ستاد، مدیر مستقیم = مدیرعامل:
  شروع ← رئیس سرمایه انسانی ← کارشناس ← مدیرکل ← (رونوشت بازرسی) ← تأیید نهایی مدیرعامل ← رئیس سرمایه انسانی (ارجاع) ← ارجاع شعبه ← حقوقی ← … (بقیه مثل بالا)
استان:
  شروع ← مدیریت شعب استان ← رئیس سرمایه انسانی ← کارشناس ← مدیرکل ← (رونوشت بازرسی) ← رئیس سرمایه انسانی (ارجاع) ← ارجاع مدیر استان ← حقوقی ← پرونده ← واریز ← ذی‌حساب ← بانک اطلاعات
رئیس حوزه حراست استان:
  مثل استان، فقط بعد از مدیریت شعب استان یک مرحله «حراست تهران» اضافه می‌شود.
