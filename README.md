# فرایندهای پست بانک

فایل‌های Camunda 7 (BPMN) و فرم‌های Form.io، هر فرایند در پوشه‌ی خودش.

| پوشه | فرایند |
|---|---|
| HousingDeposit | ودیعه مسکن مدیران غیربومی (تا تکمیل بانک اطلاعات و اعلام خروج از شمول) |
| AccountSettlement | تسویه حساب ودیعه مسکن (فرایند مستقل، `HousingDepositSettlement`) |
